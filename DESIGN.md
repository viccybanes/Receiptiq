# ReceiptIQ interface

The user delegated implementation decisions and requested a simple maintainable delivery. This surface is built directly in code; no image comp or design approval is needed for this milestone.

Mode: Operate. Direction: a document examination desk. The batch register sits beside a neutral image stage and an editable ledger. Pale mineral backgrounds, ink text, restrained evergreen actions, fine dividing rules, tabular money, compact receipt rows, and generous working space support long review sessions. A system sans keeps the offline application self-contained.

Desktop uses three columns: batch queue, image/evidence, editable fields. Smaller displays stack the viewer above the form and give the queue its own collapsible section. State is conveyed through text plus icons, not color alone. All actions have named controls and visible keyboard focus. Animations are limited to working status and respect reduced motion.

The seventh-candidate direction process was narrowed under the user's explicit instruction to work autonomously and keep scope simple. Product truth and workflow take precedence over exploratory visual ceremonies.
